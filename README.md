# DSA with Java

A comprehensive collection of Data Structures and Algorithms (DSA) implementations in Java.

## Overview

This repository contains implementations and explanations of fundamental data structures and algorithms commonly used in computer science and software development. All code is written in Java.

## Contents

### Data Structures
- Arrays
- Linked Lists
- Stacks
- Queues
- Trees (Binary Trees, BST, AVL Trees, etc.)
- Graphs
- Hash Tables / Hash Maps
- Heaps
- Tries

### Algorithms
- Sorting (Bubble Sort, Merge Sort, Quick Sort, etc.)
- Searching (Linear Search, Binary Search, etc.)
- Graph Traversal (BFS, DFS)
- Dynamic Programming
- Greedy Algorithms
- String Algorithms
- Mathematical Algorithms

## Getting Started

### Prerequisites
- Java 8 or higher
- A Java IDE (IntelliJ IDEA, Eclipse, VS Code, etc.) or command line tools

### Running the Code

1. Clone this repository:
   ```bash
   git clone https://github.com/ChapelFob80930/DSA-with-Java.git
   ```

2. Navigate to the project directory:
   ```bash
   cd DSA-with-Java
   ```

3. Compile and run individual Java files:
   ```bash
   javac FileName.java
   java FileName
   ```
